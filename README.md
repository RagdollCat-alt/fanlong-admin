# fanlong-admin

繁笼机器人 B 端管理后台。

## 当前版本

主要后台目录：`fanlong-admin-v2.1`

新增能力：

- 活动管理：月度活动总控、抽题/灯谜、猜题奖池、文字库、公奴分配、活动场域、活动结算。
- 猜题奖池配置：支持属性、货币、物品、文字结果四类奖励。
- 灯签任务：支持固定群提醒管理、待审核查看、过期扣罚记录。
- 活动状态查看：可查看抽题记录、领奖记录、灯签任务、公奴报名池、分配关系、结算档案。
- 活动数据导出：支持导出结算记录、标记/后续列表、猜题领奖记录、灯签任务记录。

## 活动管理

入口：后台侧边栏 `运营管理 -> 活动管理`

权限模块：`activities`

可配置内容：

- 活动总控：活动 ID、名称、开关、阶段、简介、公告、活动重点、预热/正式流程。
- 抽题/灯谜：题面、答案、每人可抽次数。
- 猜题奖池：配置属性、货币、物品、文字结果等奖品及权重。
- 文字结果库：维护灯签库等文本库，一行一条。
- 灯签任务：查看玩家抽中的灯签、提交状态、审核结果和过期惩罚。
- 公奴分配：查看报名池、移除报名、清空分配。
- 活动场域：场域名称、场域简介、可写剧情、判定属性、随机题面。
- 活动结算：手动给玩家录入奖励、标记、后续。

空字段可以不填。机器人展示场域时，只会展示已填写的字段。

## 猜题奖池格式

后台页面中选择即可，不需要手写 JSON。

支持：

- 属性：可指定某个属性，也可选择随机属性。
- 货币：支持虞元、名誉。
- 物品：从商店已创建物品中选择，可选择已下架但仍存在的物品。
- 文字结果：从文字库中随机抽取一条，例如 `一条灯签`。
- 权重：每个奖品可配置随机权重。
- 数值：支持固定数值，也支持随机区间。

写入后的 JSON 示例：

```json
{
  "type": "currency",
  "currency_key": "yuCoin",
  "amount_mode": "random",
  "min": 1,
  "max": 5
}
```

物品奖励示例：

```json
{
  "type": "item",
  "item_name": "金步摇",
  "amount_mode": "fixed",
  "amount": 1
}
```

灯签奖励示例：

```json
{
  "id": "p002",
  "name": "一条灯签",
  "type": "text",
  "text_pool_id": "lantern_signs",
  "weight": 50,
  "enabled": true
}
```

灯签被用户提交并由管理审核通过后，可通过机器人口令发放属性/货币奖励；若管理将灯签处理为过期，会从该用户本活动已获得的入库奖励中随机扣除 1 个。

## 活动结算录入

结算内容支持用 `+` 或 `-` 录入虞元、名誉和八项属性：

```text
虞元+20 名誉+5 口才+1
虞元-10 名誉+2 威慑+1
```

支持的名称：

- 货币：`虞元`、`名誉`
- 属性：`颜值`、`魅力`、`智力`、`商业`、`口才`、`体能`、`才艺`、`服从`、`威慑`

标记和后续只进入活动档案，不改玩家数值：

```text
虞元+20 名誉+5 口才+1 标记:席间得名 后续:席后私谈
```

## 数据文件

活动后台读写机器人插件的数据目录：

```text
fanlong_activity/data/
```

主要文件：

- `activities.json`：活动配置总表，包含当前活动 ID。
- `activity_states/{activity_id}.json`：每个活动独立状态，包含抽题、领奖、灯签、公奴、结算记录。
- `activity_config.json`、`activity_state.json`：旧格式兼容文件。

如部署目录不同，可在 `fanlong-admin-v2.1/config.php` 中定义：

```php
define('ACTIVITY_DATA_PATH', '你的 fanlong_activity/data 绝对路径');
```

## 与机器人同步

活动插件会在活动相关口令触发时自动读取 JSON 文件，所以后台保存后通常不需要重启机器人。

如果机器人没有按后台内容响应，优先在群内用管理员口令检查：

```text
活动诊断
活动路径
活动重载
```

`活动诊断` 会显示机器人实际读取的活动数据路径、当前活动 ID、阶段和开关状态。
